THREAD & CO. — FRIEND TEST DEPLOYMENT

This is a fictional clothing shop with a scripted helper. It has no AI or API key. Checkout and payments are demo only.

LOCAL TEST
1. Open this folder in VS Code.
2. Run: python -m pip install -r requirements.txt
3. Run: python app.py
4. Visit http://127.0.0.1:5000

PUBLIC TEST LINK
1. Put this folder in a GitHub repository. Do not add passwords or private keys.
2. Sign in to Render and choose New > Blueprint.
3. Connect the repository containing render.yaml.
4. Review and deploy the service.
5. Share the onrender.com URL Render gives you.

The included render.yaml contains the web service settings. Render's current plan and limits may change, so check those before deploying. The public site is only a demo: it does not take payments or save customer orders.
